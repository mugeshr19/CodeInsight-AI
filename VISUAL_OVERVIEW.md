## 🔄 Data Flow

```
┌──────────────────────────────────────────────────────────────┐
│                    REGISTRATION FLOW                          │
└──────────────────────────────────────────────────────────────┘
User Input → RegisterPage → API Service → AuthController
    → AuthService → UserRepository → MongoDB
    → JWT Token → AuthContext → Dashboard

┌──────────────────────────────────────────────────────────────┐
│                    CODE ANALYSIS FLOW                         │
└──────────────────────────────────────────────────────────────┘
Code Input → DashboardPage → API Service → AnalysisController
    → AnalysisService → StaticAnalyzer (Complexity)
    → GroqService (AI Analysis) → SubmissionRepository
    → MongoDB → ResultPage (Display)

┌──────────────────────────────────────────────────────────────┐
│                    ANALYTICS FLOW                             │
└──────────────────────────────────────────────────────────────┘
User Request → AnalyticsPage → API Service → UserController
    → UserService → SubmissionRepository → MongoDB
    → Aggregation → Charts (Recharts)
```
